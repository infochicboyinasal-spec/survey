# ChicBoy Inasal - Forms

Public forms and pages for ChicBoy Inasal, one folder each:

- `ube/` - Ube taste test survey (16-30 Nov 2026). Answers and voucher codes are handled by the ChicBoy Google Apps Script web app.
- `staff/` - Mall Staff Card sign-up (`index.html`) and personal card page (`card.html`). Registrations and codes stay in the private `programs` schema of the ChicBoy Supabase project; the page can only call `member_register` and `member_card`.

Planned: `vip/` - VIP card registration.
